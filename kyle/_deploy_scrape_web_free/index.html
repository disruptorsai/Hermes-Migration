Scraping is the slow, repetitive, technical work that eats your day — copy-pasting from LinkedIn, watching prices on Amazon, pulling agent contacts off Zillow, building lead lists by hand. The right tool turns weeks of work into a single prompt. This is that tool.

Meet ScrapeGraph AI

ScrapeGraph AI is a free, MIT-licensed Python library that uses an LLM to scrape any website with a single plain-English prompt. No CSS selectors. No XPath. No brittle rules that break when a site updates. You describe what you want; the model figures out how to extract it.

github.com/ScrapeGraphAI/Scrapegraph-ai
Open source. MIT licensed. Active community. The library is free to use forever.
Pluggable LLM backend
Drop in OpenAI, Anthropic, or run a local model with Ollama. Pay pennies, or pay nothing.

FIELD GUIDE 002 · 02 / SETUP IN TEN MINUTES

Section 02Install the library.
Pick your model.

Two steps stand between you and a working scraper. Total time on a clean machine: ten minutes.

1

Install ScrapeGraph AI

Terminal · ~2 minutes

Open your terminal and run these two commands. Playwright handles the browser layer that lets the scraper render JavaScript-heavy sites.

# Install the library and its browser engine
pip install scrapegraphai
playwright install
Recommended Run this inside a Python virtual environment (python -m venv venv) to keep dependencies isolated from the rest of your system.
2

Choose your LLM backend

Hosted API or local model

ScrapeGraph AI is model-agnostic. Pick the lane that fits your speed, privacy, and budget needs.

Option Where Cost Best for
OpenAI Recommended platform.openai.com Pennies per scrape Fastest setup. Best accuracy on messy pages. GPT-4o-mini is the sweet spot.
Anthropic console.anthropic.com Pennies per scrape Long context, strong reasoning. Great for multi-page extraction.
Ollama Free ollama.com $0 — runs locally Total privacy. Zero ongoing cost. Slower; quality varies by model.

If you go local with Ollama

Install Ollama from ollama.com, then pull a model. Llama 3.2 is a solid starting point that balances speed and quality on consumer hardware.

# Pull a local model — runs entirely on your machine
ollama pull llama3.2

FIELD GUIDE 002 · 03 / YOUR FIRST SCRAPE

Section 03Run your first scrape.

The same library, two flavors. Copy the snippet that matches the model you picked, swap the URL and the prompt for your target, and run it.

3

Hosted API — OpenAI GPT-4o-mini

Best accuracy · pennies per run

Paste your API key, point at any public URL, write a prompt that names the fields you want, and run the script. The output is a Python dict you can save as JSON.

from scrapegraphai.graphs import SmartScraperGraph

graph_config = {
    "llm": {"api_key": "YOUR_OPENAI_KEY", "model": "openai/gpt-4o-mini"},
    "verbose": True, "headless": True,
}

scraper = SmartScraperGraph(
    prompt="List every product name, price, and rating.",
    source="https://example.com/products",
    config=graph_config,
)
print(scraper.run())
3b

Local model — Ollama (Llama 3.2)

$0 ongoing · stays on your machine

Same shape, no API key. Make sure ollama serve is running in another terminal before you launch the scraper.

from scrapegraphai.graphs import SmartScraperGraph

graph_config = {
    "llm": {
        "model": "ollama/llama3.2", "temperature": 0,
        "format": "json", "model_tokens": 8192,
        "base_url": "http://localhost:11434",
    },
    "verbose": True, "headless": True,
}

scraper = SmartScraperGraph(
    prompt="Extract every job title, company, and location.",
    source="https://example.com/jobs",
    config=graph_config,
)
print(scraper.run())
Checkpoint Run the script. You should see a printed JSON-shaped Python dict in your terminal. If you do, you're done — every future scrape is a variation on this same eight-line pattern.

Section 04You don't need to know Python.
You need to know what data you want.

Step 4 is the unlock. Hand the work off to Claude Code or OpenAI Codex. Describe the data, paste in the target URL, and ship a working scraper without writing a line yourself.

4

Prompt your AI assistant

Claude Code · Codex · Cursor

Open your AI coding assistant and paste a prompt like the one below. Swap in your target URL and the exact fields you need. The assistant generates a runnable script you can execute immediately.

# Paste into Claude Code or Codex

Using the ScrapeGraphAI Python library with OpenAI GPT-4o-mini,
write a script that scrapes [TARGET URL] and returns
a JSON list of every [ENTITY] with the following fields:
[FIELD 1], [FIELD 2], [FIELD 3].

Save the output to scrape_output.json.
The Insight The bottleneck for most operators is not Python skill — it's knowing what to ask for. Once you can describe the data clearly, an AI assistant writes the scraper.

The pipelines under the hood

ScrapeGraph AI ships with five graph types. For 90% of jobs, SmartScraperGraph is all you need. Reach for the others when you scale up.

Pipeline Use it for
SmartScraperGraph Default Single page, one prompt. Your daily driver.
SmartScraperMultiGraph A list of URLs scraped in parallel — same prompt, many pages.
SearchGraph Run a search query, then scrape the top N results in one call.
ScriptCreatorGraph Generates a reusable, standalone Python script for the target site.
SpeechGraph Extract data and return the result as synthesized audio output.

The fine print — what to expect

  • The tool is free, inference is not. OpenAI and Anthropic charge pennies per scrape. Budget accordingly on large jobs.
  • Ollama is $0 but variable. Local models are slower and quality depends on your hardware and chosen model.
  • No GUI. Everything runs from Python or an AI code assistant — there is no point-and-click interface.
  • Scale needs proxies. Heavy-volume scraping triggers rate limits. Add a basic proxy rotation layer once you cross thousands of requests per run.
