Section 01One command.
A full SEO team.

Most SEO work is the same audit, repeated by hand, over a few weeks. Claude SEO compresses that into a single command — parallel agents covering technical, content, schema, AI search, local, e-commerce, and international — converging into one prioritized plan.

The repo

Claude SEO is an open-source plugin for Claude Code. You don't wire up the agents or decide which checks to run. Point it at a URL — it spins up specialists across technical SEO, content quality (E-E-A-T), Schema.org, AI search (GEO), local, e-commerce, and international SEO, then merges everything into one prioritized plan. Every recommendation comes with a "how would we know this failed?" check, so nothing is hand-wavy.

FIELD GUIDE 003 · 02 / INSTALL IN TWO MINUTES

Section 02Install in two minutes.

Three install paths. Pick the one that matches your machine. No API keys required to start — everything runs locally on first launch.

1

Plugin install — fastest

Claude Code 1.0.33+ · ~30 seconds

If you're on a recent Claude Code build, install directly from the plugin marketplace inside the Claude Code session.

/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
2

Manual install — macOS / Linux

Clone & run · ~90 seconds

Clone the repo and run the install script. Works on any modern macOS or Linux machine with Python 3.10+.

git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git
bash claude-seo/install.sh
3

Manual install — Windows

PowerShell · ~90 seconds

Same flow, PowerShell variant. The execution policy bypass is scoped to this single script run.

git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git
powershell -ExecutionPolicy Bypass -File claude-seo\install.ps1

Requirements

  • Python 3.10+ and the Claude Code CLI — both required.
  • Playwright Chromium — auto-installed; used for JS-rendered / SPA crawls.
  • Optional: Google API credentials for live CWV, Search Console, and GA4 data — run /seo google setup when you're ready.

FIELD GUIDE 003 · 03 / RUN YOUR FIRST AUDIT

Section 03Run your first audit.

Two commands. Ten minutes. A full FULL-AUDIT-REPORT.md with a 0–100 score, your critical issues ranked, and every fix tagged with the observation it rests on plus the leading indicator to watch.

1

Open Claude Code

Terminal · 1 line
claude
2

Fan out the full audit

Parallel agents · 10–15 minutes

Point Claude SEO at the URL. Specialist agents spin up in parallel, each owning a slice of the audit, then converge into a single prioritized report.

/seo audit https://your-site.com

Then go deeper on what the audit flagged

The audit surfaces the priorities. These commands drill into each one with a focused specialist agent.

# Deep single-page analysis: on-page, content quality, schema
/seo page https://your-site.com/about

# Detect, validate, and generate Schema.org markup
/seo schema https://your-site.com

# AI search readiness — AI Overviews / GEO, passage citability
/seo geo https://your-site.com

# Technical SEO across 9 categories — CWV, crawlability, indexation
/seo technical https://your-site.com

# Strategic plan tuned to your business type
/seo plan saas      # or: local · ecommerce · publisher · agency
What You Get Back A FULL-AUDIT-REPORT.md file with a 0–100 site score, every critical issue ranked, and a dependency-ordered action plan. Each recommendation carries a failure check and a leading indicator — falsifiable, not promotional.

FIELD GUIDE 003 · 05 / UNDER THE HOOD

Section 05How it actually works.
Why it's different.

You run one command. Under the hood, three stages do the heavy lifting — industry detection, parallel dispatch, and synthesis.

01 · DETECT
Industry detection
Identifies whether you're SaaS, local, e-commerce, publisher, or agency — and tunes the audit to the playbook that matters.
02 · DISPATCH
Parallel agents
Spins up to 15 specialist agents at once. Each owns a slice — technical, content, schema, GEO, local — and runs independently.
03 · SYNTHESIZE
Prioritized plan
Collects every finding, scores them through a 10-principle framework, and sequences them into a dependency-ordered action plan.

Why it's different from every other SEO tool

AI-SEARCH FIRST
Aligned with Google's AI Optimization Guide. Scores passage citability and entity presence — not last year's checklist.
FALSIFIABLE
Every recommendation ships with an explicit failure check and a leading indicator. No vibes-based advice.
LOCAL BY DEFAULT
No data leaves your machine unless you opt into an enrichment API. No per-domain pricing, no lock-in.
