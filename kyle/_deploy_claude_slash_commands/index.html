The Essential Slash Commands

Twenty commands that make
Claude Code actually fast.

The slash commands seasoned operators reach for daily — pulled from real Claude Code users shipping production work. Keep this open in a second monitor. Type the slash, type the command, ship.

/clear
Wipes the conversation and frees the context window for a fresh task.
/compact
Summarizes the current session in place so you can keep going without losing the thread.
/init
Generates a CLAUDE.md so Claude understands your repo's conventions on every run.
/model
Swaps between Opus, Sonnet, and Haiku mid-session to match cost and capability.
/agents
View, edit, and spin up specialized sub-agents that handle scoped tasks in parallel.
/mcp
Connect Model Context Protocol servers — databases, Slack, Notion, anything with an MCP.
/memory
Open and edit the persistent memory files Claude carries between sessions.
/review
Runs a structured code review on the current branch before you open the PR.
/pr-comments
Pulls down GitHub PR comments so Claude can address every reviewer note in one pass.
/security-review
Audits pending changes for credential leaks, injection risk, and common vulnerabilities.
/hooks
Wire shell hooks that fire on tool calls — auto-format, lint, or block dangerous actions.
/permissions
Allowlist or deny specific tools and paths so Claude stops asking for the same approval.
/cost
Shows tokens spent and dollar cost for the current session in real time.
/resume
Reopens a previous session from history exactly where you left off.
/export
Saves the full transcript to a file — perfect for handoffs and audit trails.
/todos
Surfaces Claude's live task list so you can see exactly what's planned and what's done.
/status
Reports account, active model, working directory, and current permission mode.
/add-dir
Grants Claude access to an additional directory outside the launch folder.
/ide
Connects to VS Code or JetBrains for inline diffs, jump-to, and selection context.
/help
Lists every available slash command, including ones added by your installed plugins.
Pro Tip
Pair /init on day one with /compact before context fills up, and /clear at every new task. That single rhythm is the difference between Claude as a toy and Claude as an operator.
